# KAIRO Club — Static Landing Page

A dark, minimal club landing page inspired by the supplied KAIRO logo.

## Files

```text
kairo-club-landing-page/
├── index.html
├── style.css
├── script.js
└── assets/
    └── kairo-logo.png
```

## Run

No framework or build step is required.

Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize

### Instagram
Open `script.js` and change:

```js
const INSTAGRAM_URL = "https://www.instagram.com/";
```

to the club's real Instagram profile URL.

### Business email
The contact section is already connected to:

`shahvihaan39@gmail.com`

The button uses `mailto:` so it opens the visitor's default email application.

### Content
Edit the text directly in `index.html`.

### Design
All colors, spacing, typography and responsive behavior are in `style.css`.

## Design direction

- Near-black / charcoal background
- White and silver typography
- Thin borders and subtle gradients
- Serif display typography paired with a clean sans-serif
- Large editorial-style spacing
- Minimal motion and scroll reveals
- Responsive mobile navigation
